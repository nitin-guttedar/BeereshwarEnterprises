## ⚡ Key Features

- **Responsive Header & Modern Navigation**: Streamlined 4 primary sections: *Home*, *About Us*, *Services* (with an interactive module dropdown), and *Contact Us*.
- **Interactive Requisition Calculator**: Instant workforce sizing, shift configuration, and monthly wage estimation engine.
- **Coverage Radar (100+ km Radius)**: Radial transit matrix visualising dispatch logistics from the Thandavpura central depot to Kadakola (TVS Belt), Nanjangud, Hebbal, Hootagalli, and Metagalli.
- **500+ Worker Directory**: Searchable, filterable roster by trade, native origin (UP/Bihar/Jharkhand), deployment plant, and biometric/medical verification status.
- **Credential-Gated Admin & Client HR Portal**:
  - Secure authentication modal preventing unauthorized public access.
  - Multi-tenant role management (SBE Agency Admin vs. Client Plant HR).
  - Shift roll-call punch verification simulator (Shift A, B, C nocturnal).
  - Billing timesheet generator (.CSV) and statutory compliance docket downloader.
- **Full Dual Theming**: Crisp, accessible Dark & Light modes with WCAG compliant text contrast.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/nitin-guttedar/BeereshwarEnterprises.git
cd BeereshwarEnterprises
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```
Open your browser at `http://localhost:5173/` (or the port indicated in terminal).

### 4. Build for production
```bash
npm run build
```
